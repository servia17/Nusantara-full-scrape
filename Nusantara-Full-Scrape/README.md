# House of Nusantara — Local Runtime

Run the captured experience and its local API:

```bash
npm start
```

Open http://localhost:3000. The catalogue, listing detail, filtering, quote submission, concierge chat, and local admin/partner dashboard requests are served locally. Submitted data is stored in `data/` (created on first write).

For the dashboard demo, use any non-empty email and password. An email beginning with `admin` opens the admin dashboard; other emails open the partner dashboard.
